## English — Default

### Name

Sade Markdown Viewer

### Short description

Read Markdown files as clean, comfortable pages with system, light, and dark themes.

### Detailed description

Sade Markdown Viewer makes `.md` and `.markdown` files easy to read directly in Firefox. “Sade” means “simple” in Turkish, reflecting the extension's clean and focused design.

Features:

- System, light, and dark themes
- Remembers your theme preference
- Supports headings, lists, links, images, blockquotes, and code blocks
- Works with local files and direct Markdown URLs
- No tracking, advertising, accounts, or external services
- No build dependencies

Use the theme button to switch between System → Light → Dark.

### Privacy

The extension does not collect, transmit, or share personal data. Only the selected theme preference is stored in Firefox's local extension storage. Markdown content never leaves the device or the page being viewed.

Remote images referenced by a Markdown document may be loaded by Firefox from addresses specified by the document's author.

### Permission explanations

- **Storage:** Remembers the selected theme.
- **Local file access:** Formats `.md` and `.markdown` files opened in Firefox.
- **Website access:** Formats only direct Markdown pages whose addresses end in `.md` or `.markdown`.

## Türkçe

### Ad

Sade Markdown Viewer

### Kısa açıklama

Markdown dosyalarını sistem, açık ve koyu temayla temiz ve rahat okunabilen sayfalar olarak görüntüleyin.

### Ayrıntılı açıklama

Sade Markdown Viewer, `.md` ve `.markdown` dosyalarını doğrudan Firefox içinde rahatça okumanızı sağlar. Adındaki “Sade”, eklentinin temiz ve odaklı tasarım yaklaşımını ifade eder.

Özellikler:

- Sistem, açık ve koyu tema
- Tema tercihini hatırlama
- Başlık, liste, bağlantı, görsel, alıntı ve kod bloğu desteği
- Yerel dosyalar ve doğrudan Markdown bağlantılarıyla çalışma
- İzleyici, reklam, hesap veya harici hizmet yok
- Derleme bağımlılığı yok

Tema düğmesi Sistem → Açık → Koyu seçenekleri arasında geçiş yapar.

### Gizlilik

Eklenti kişisel veri toplamaz, iletmez veya üçüncü taraflarla paylaşmaz. Yalnızca seçilen tema tercihi Firefox'un yerel eklenti depolama alanında tutulur. Markdown içeriği cihazdan veya görüntülenen sayfadan dışarı gönderilmez.

Markdown belgelerindeki uzak görseller, belgenin yazarı tarafından belirtilen adreslerden Firefox tarafından yüklenebilir.

### İzin açıklamaları

- **Depolama:** Seçilen temayı hatırlamak için kullanılır.
- **Yerel dosya erişimi:** Firefox'ta açılan `.md` ve `.markdown` dosyalarını biçimlendirmek için kullanılır.
- **Site erişimi:** Yalnızca adresi `.md` veya `.markdown` ile biten doğrudan Markdown sayfalarını biçimlendirmek için kullanılır.
